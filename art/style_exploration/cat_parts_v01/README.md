# Cat Parts Study v01

This local research pass explores a detachable Catgirl species and wardrobe kit over the generic paper-doll mannequin.

The PNG is intentionally git-ignored with the rest of generated research media. It is a visual design board, not a shippable sprite sheet: the apparent checkerboard is baked into opaque pixels rather than genuine transparency.

The production contract and current in-engine implementation are documented in `docs/paper_doll_parts.md`.
