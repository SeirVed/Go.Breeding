# Development Map

> **Status: living roadmap.** Checked against prototype version 0.2.4. A roadmap item is not implemented unless it is explicitly marked implemented.

## Implemented prototype foundation

- Main menu framework: New, Continue, Load, Options, Gallery, and Exit.
- Placeholder introduction and map navigation for ranch, town, forest, and other destinations.
- Layered text-emoji creature composites and an open-ended data registry.
- Gallery and old-town Dev Progress presentation.
- Three 81-cell directional boards: Jack & Jill, Jack & Jack, and Jill & Jill.
- Nine male-frame and nine female-frame archetype names over the shared 3×3 size/morphology model.
- Honest 0% commission state and `PLACEHOLDER ACTIVE` messaging.
- `Emoji Bonk v0` on Breed and in commission previews.
- Deterministic prototype offspring generation and local save framework.

See `VERSION.md` and `CHANGELOG.md` for exact release history.

## Next: animation foundation

- Build one real universal paired paper-doll template.
- Define Actor A/Actor B anchors, sprite-slot contracts, measurements, and anatomy compatibility tags.
- Implement deterministic best-fit resolution with Emoji Bonk as the last-resort placeholder.
- Report playable coverage separately from bespoke commission progress.
- Validate one newly added monster flows through the registry without hard-coded roster-count changes.

## Next: Guild Star Ballot

- Add one global Gold/Silver/Bronze ballot per player across all three boards.
- Display raw rank totals, unique voters, and the public `3G + 2S + B` score.
- Build the small HTTPS API, persistent store, privacy notice, abuse controls, and aggregate dashboard.
- Report popularity by board, direction, ordered size, ordered morphology, archetype, and exception tag.
- Keep admin progress controls separate from player voting credentials.

This system is specified in `dev_metrics.md`; none of its network components exist yet.

## Systems depth

- Complete and test the documented genetics model, trait inheritance, compatibility, and stability consequences.
- Add progression resources, facilities, environments, Gene-Gel, and laboratory routes.
- Add readable codex explanations and near-miss unlock hints.
- Expand the creature registry continuously rather than toward a fixed final count.

## Long-tail production

- Add Small, Large, morphology, archetype, and exception-tag paper-doll templates in demand-informed order.
- Add bespoke ordered species-pair variants where they deliver strong value.
- Improve palettes, particles, additive motion, sound, thumbnails, and accessibility.
- Record credits, status, and coverage changes in data and changelog entries.

## Deferred possibilities

- Optional accounts for stronger ballot identity and cross-device sync.
- Import/export creature provenance.
- Console or Android support after PC fundamentals and performance testing.
- Seed rarity/decay and specialised laboratory mechanics only after the core loop proves worthwhile.
