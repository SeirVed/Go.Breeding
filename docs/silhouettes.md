# Silhouettes

> **Status: reference data model.** The nine body archetypes and roster mappings exist; production paper-doll art does not.

## Primary families (standing height)

- **Small:** below 4′0″ (below 1.22 m). The current review reference is 3′6″ / 1.07 m.
- **Medium:** 4′0″ to below 8′0″ (1.22–2.44 m), centred approximately on 6′0″ / 1.83 m. Individual height remains important inside this deliberately broad humanlike band.
- **Large:** 8′0″ and above (2.44 m+). The current review reference is 8′6″ / 2.59 m.

These are coarse biomechanical categories, not automatic uniform scales. Every production character records an explicit standing height in addition to its size family. The first Catgirl base is 5′5″ / 1.65 m and therefore maps to **Medium–Neutral**.

## Secondary modifiers (morphology)
- **Feral**: forward‑lean; digitigrade; pronounced ears/tails/muzzle.
- **Neutral**: balanced demi‑human.
- **Refined**: upright; subtle animal features.

Matrix → **9 base silhouettes** (Size × Morph). Optional tags layered later:
- **Winged**, **Exotic** (slime/naga), **Bestial** (quadruped), **Tauric** (dual-body).

## Asset implications (2D)
- Begin with one shared locomotion paper-doll, then add reusable paired templates per base silhouette as production permits.
- Characters choose a neutral base mannequin, then compose reusable species, wardrobe and identity part sets. Ears, tails, horns, fur, scales, skin treatment and palettes never live in the rig profile itself.
- Development axis (neotenous/peramorphous) drives **proportion presets** (head/limb scaling) and **anim speed** later.

The creature registry is open-ended. New monsters declare stable IDs, body mappings, measurements, and exception tags, then inherit the most compatible available template. See [Paired Paper-Doll Animation Pipeline](animation_pipeline.md).
