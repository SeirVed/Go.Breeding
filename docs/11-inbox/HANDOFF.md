## Handling a new item

Record a short title, the user's intended benefit, date, likely owning area and whether it is proposed, accepted for planning, routed or dropped. Preserve unresolved questions. Group duplicates by linking them; avoid creating several competing specifications.

## Suggested next task and acceptance

When asked to capture an idea, add one concise note and route it if the owner is clear. Cross-area priority decisions go to Project HQ. Use a private subfolder when the note contains internal material. Completion means the idea is findable and its status is explicit; it does not require implementing it or interrupting unrelated work.
